# Video Compilation Page

A web page about front-end web development with an introduction and three sections (HTML, CSS and JavaScript), each with a short description and an embedded YouTube tutorial video. Built as part of the freeCodeCamp curriculum.

## Live Demo

[View the project](https://aqeelahlabs.github.io/YOUR-REPO-NAME/)

## Features

- A main heading and introduction to front-end web development
- Three sections, each with a heading, a description and an embedded video
- YouTube players with fullscreen support
- Permissions set for features like autoplay, picture-in-picture and encrypted media

## What I Practised

- Structuring a page with semantic HTML5 elements (`main`, `section`)
- Creating a heading hierarchy with `h1` and `h2`
- Embedding external videos with the `iframe` element
- Using the `width`, `height`, `src` and `title` attributes
- Controlling browser features with the `allow` attribute
- Setting a `referrerpolicy` to control what referrer information is sent
- Enabling fullscreen with `allowfullscreen`

## Built With

- HTML5
- YouTube embed
